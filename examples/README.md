# TypePress Examples

Each example is a self-contained input file. Render it with:

```bash
typepress examples/markdown-all-features.md -o out.pdf
# or via the HTTP server:
curl -X POST localhost:8787/render -H 'Content-Type: application/json' \
  -d '{"markdown": "<contents>", "options": {"math": true}}'
```

| Example | Shows | Input |
|---|---|---|
| `markdown-all-features.md` | Markdown: headings, tables, code, math, mermaid, emoji, CJK | Markdown |
| `html-css-layout.html` | HTML + CSS Grid/table layout, inline styles | HTML |
| `header-footer.md` | Running headers/footers + page numbers | Markdown |

> PDF outputs are regenerated by `examples/render.sh` into
> `examples/out/` (gitignored — the `.md`/`.html` inputs are the source
> of truth).

## 1. markdown-all-features.md

Renders a document exercising the full pipeline:

- ATX/Setext headings, blockquotes, lists (ordered/unordered/nested)
- Tables with alignment
- Fenced code blocks with syntax highlighting
- Inline math (`$...$`) and display math (`$$...$$`)
- Mermaid diagrams (`mermaid-render` feature)
- Emoji, CJK text, links, images, horizontal rules

```bash
typepress examples/markdown-all-features.md -o examples/out/markdown-all-features.pdf
```

## 2. html-css-layout.html

A raw HTML document with CSS Grid layout — the differentiator vs
browser-based engines (no browser process, deterministic output).

```bash
typepress examples/html-css-layout.html -o examples/out/html-css-layout.pdf
```

## 3. header-footer.md

Shows `--header` / `--footer` with the built-in page-number tokens.

```bash
typepress examples/header-footer.md \
  --header "TypePress Example" \
  --footer "Page {page} of {pages}" \
  -o examples/out/header-footer.pdf
```
